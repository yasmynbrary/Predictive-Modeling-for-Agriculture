# Predictive-Modeling-for-Agriculture
# Crop Prediction

## About the Project
In this project, I used machine learning to explore soil data and find which soil feature is best for predicting the type of crop to grow.

## Dataset
The project uses `soil_measures.csv`, which contains soil measurements and crop types.

The dataset includes:
- `N`: Nitrogen level.
- `P`: Phosphorus level.
- `K`: Potassium level.
- `pH`: Soil pH value.
- `crop`: Crop type.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression

## What I Did
- Prepared the data for machine learning.
- Split the data into training and testing sets.
- Trained a model using each soil feature separately.
- Compared the model scores to find the best predictive feature.

## Goal
The goal of this project was to practice classification and understand how soil measurements can help predict crop types.
